# Attendance Analysis

## Project Overview

This project is an Excel-based analysis of a company's employee attendance dataset. The goal is to clean, process, and analyze attendance data to generate useful attendance and overtime reports.

## Dataset

The dataset contains 100,000 rows of employee attendance records for August 2026.

It includes information such as:

* Employee ID (NIK)
* Employee Name
* Attendance Date
* Clock-in Time
* Clock-out Time

## Tools Used

* Microsoft Excel
* Excel Formulas
* Data Formatting

## Analysis Performed

The analysis focuses on:

* Attendance days of each employee
* Attendance consistency of each employee
* Overtime hours of each employee
* Attendance and overtime summary

## Excel Concepts Used

* Data Cleaning
* Data Formatting
* Date and Time Functions
* Conditional Logic
* `COUNTIFS`
* `SUMIFS`
* `NETWORKDAYS.INTL`
* `IF`
* `INDIRECT`

## Goals

The main goal of this project is to transform raw attendance data into a structured report that provides an overview of employee attendance and overtime.

## Key Questions

* How many days did each employee attend during the month?
* How consistent was each employee's attendance?
* How many overtime hours did each employee work?
* What does the overall attendance pattern look like?

## Project Output

The final output is an Excel-based attendance report that summarizes employee attendance and overtime data.
