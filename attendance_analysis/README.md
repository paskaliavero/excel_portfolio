## Attendance Analysis

# Project Overview
This is an excel-based analysis of an attendance dataset of a company. The goal is to clean and reporting the key point of attendance.

## Dataset
The dataset contains 100.000 rows of data in a month which is August 2026. It includes details such as NIK, Name, Date, Clock in Times, and Clock out Times

## Tools Used
- Excel Spreadsheet
- Excel Formulas
- Data Formatting

## Analysis Performed
- Attendance day of each employees
- Assiduousness of each employees
- Overtime of each employees

## Excel Concept Used
- Data cleaning
- Data Formatting
